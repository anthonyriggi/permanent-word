# Source

Permanent Word currently uses a Project Gutenberg KJV source text.

The source workflow is designed to keep the text traceable, reproducible, and verifiable.

## Source files

```text
source/kjv-gutenberg.txt
source/kjv-gutenberg.sha256.txt
source/source-manifest.json
source/full-bible-gutenberg.json
source/full-bible-gutenberg.sha256.txt
```

## Source pipeline

```text
Project Gutenberg KJV text
→ source/kjv-gutenberg.txt
→ source/kjv-gutenberg.sha256.txt
→ source/full-bible-gutenberg.json
→ source/full-bible-gutenberg.sha256.txt
→ data/*.json
→ data/*.sha256.txt
→ data/manifest.json
→ data/manifest.sha256.txt
→ release-manifest.json
→ release-manifest.sha256.txt
→ dist/permanent-word-vX.Y.Z.zip
→ dist/permanent-word-vX.Y.Z-site/
```

## Download source

```bash
npm run source:download
```

Writes:

```text
source/kjv-gutenberg.txt
source/kjv-gutenberg.sha256.txt
source/source-manifest.json
```

## Check source

```bash
npm run source:check
```

Verifies:

```text
source/kjv-gutenberg.txt
```

against:

```text
source/kjv-gutenberg.sha256.txt
```

## Import full Bible

```bash
npm run source:import:full
```

Expected import:

```text
Books: 66
Chapters: 1,189
Verses: 31,102
```

Generated files:

```text
source/full-bible-gutenberg.json
source/full-bible-gutenberg.sha256.txt
```

## Build reader data

```bash
npm run build:data
```

Generated files:

```text
data/manifest.json
data/manifest.sha256.txt
data/<book>-<chapter>.json
data/<book>-<chapter>.sha256.txt
```

Example:

```text
data/psalms-23.json
data/psalms-23.sha256.txt
```

## Compact publish data

Generated by:

```bash
npm run build:site
```

or:

```bash
npm run build:publish
```

Output:

```text
dist/permanent-word-vX.Y.Z-site/
```

Compact data files:

```text
data/manifest.json
data/manifest.sha256.txt
data/bible.json
data/bible.sha256.txt
```

The compact bundle keeps the file count low for IPFS/Arweave uploads while preserving the same chapter hashes.

## Release manifest

Generated files:

```text
release-manifest.json
release-manifest.sha256.txt
```

Check with:

```bash
npm run check:release
```

The release manifest records each included file with:

- path
- byte size
- SHA-256 hash

## Archive bundle

Generated by:

```bash
npm run build:bundle
```

Output:

```text
dist/permanent-word-vX.Y.Z.zip
dist/permanent-word-vX.Y.Z.zip.sha256.txt
```

Check with:

```bash
npm run check:bundle
```

## Full verification

```bash
npm run verify
```

Runs:

```text
source check
→ full Bible import
→ data build
→ data check
→ release manifest build
→ release manifest check
```

## Canonical text

The canonical generated text is the Scripture text imported from the tracked source file.

Metadata includes:

- book names
- chapter numbers
- slugs
- file paths
- source display fields
- release manifest summary fields
- compact publish metadata
